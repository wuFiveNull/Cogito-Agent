# Cogito-Agent

Local-first personal Agent runtime with long-term memory, governed capabilities, traceable execution, reusable skills, and constrained proactive behavior.

## Quick Start

```bash
pip install -e .
cogito migrate
cogito chat
```

## Requirements

- Python 3.12+

## Development

```bash
pip install -e ".[dev]"
pytest
ruff check src/
mypy src/
```
